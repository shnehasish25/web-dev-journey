MongoDB Day 297

Aggregation Framework Part 2: $group & Accumulators

Grouping data with $group and calculating $sum, $avg, $min, $max.

Executable Query Snippet:

// Day 297: Grouping & Metrics
db.orders.aggregate([
  { $match: { status: "DELIVERED" } },
  { $group: {
      _id: "$restaurantName", // Group by restaurant
      totalRevenue: { $sum: "$totalAmount" },
      avgOrderValue: { $avg: "$totalAmount" },
      orderCount: { $sum: 1 }
    }
  },
  { $sort: { totalRevenue: -1 } }
]);
