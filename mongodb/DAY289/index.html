MongoDB Day 289

CRUD: Query Filters & Logical Operators

find() and findOne() with $gt, $gte, $in, $and, $or comparison operators.

Executable Query Snippet:

// Day 289: Query Filters
// Find high-rated pure veg restaurants in Koramangala
db.restaurants.find({
  $and: [
    { city: "Bengaluru" },
    { locality: "Koramangala" },
    { isVeg: true },
    { rating: { $gte: 4.5 } }
  ]
});
