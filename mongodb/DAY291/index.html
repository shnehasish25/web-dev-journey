MongoDB Day 291

CRUD: updateOne, updateMany & $inc

Modifying documents with $set, $inc, $unset, and the upsert flag.

Executable Query Snippet:

// Day 291: Updates
// Increment total reviews count and update rating
db.restaurants.updateOne(
  { name: "Udupi Tiffin Hall" },
  { 
    $set: { rating: 4.7 },
    $inc: { totalReviews: 1 } // Atomic increment
  },
  { upsert: true }
);
