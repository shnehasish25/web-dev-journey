Generating and Linking an SSH Key with GitHub:

1. Generate modern Ed25519 SSH key pair:
   ssh-keygen -t ed25519 -C "kushal.codes@gmail.com"

2. Start the ssh-agent in the background:
   eval "$(ssh-agent -s)"

3. Add key to agent:
   ssh-add ~/.ssh/id_ed25519

4. Copy public key to clipboard:
   cat ~/.ssh/id_ed25519.pub

5. Add to GitHub:
   GitHub.com -> Settings -> SSH and GPG Keys -> New SSH Key -> Paste public key!

6. Test connection:
   ssh -T git@github.com
   (Output: Hi Kushal! You've successfully authenticated...)
