Web Development Glossary (<dl>)

Quick revision of core web architecture concepts before viva exams:

HTTP / HTTPS
HyperText Transfer Protocol (Secure). The protocol used to transmit web pages across the internet on port 80 (HTTP) or port 443 (HTTPS with SSL/TLS encryption).
DNS (Domain Name System)
The phonebook of the internet. Translates human-friendly domain names like google.com into machine IP addresses like 142.250.190.46.
DOM (Document Object Model)
The tree-structured object representation of an HTML document created by the browser in RAM, which JavaScript can dynamically manipulate.
Semantic HTML
Using tags that convey meaning about their content (e.g. <article>, <nav>, <footer>) rather than generic presentation tags like <div>.
