5th Semester Computer Science Syllabus

Practicing deep nested lists with subject modules and credits.

  1. Database Management Systems (DBMS) - 4 Credits
    • Module 1: Introduction to Database Systems & ER Diagrams
    • Module 2: Relational Model & SQL Queries
      1. DDL Commands (CREATE, ALTER, DROP)
      2. DML Commands (SELECT, INSERT, UPDATE, DELETE)
      3. Subqueries and JOIN operations
    • Module 3: Normalization (1NF, 2NF, 3NF, BCNF)
    • Module 4: Transaction Processing & ACID Properties
  2. Operating Systems (OS) - 4 Credits
    • Module 1: Process Management & Threads
    • Module 2: CPU Scheduling Algorithms (FCFS, SJF, Round Robin)
    • Module 3: Deadlocks & Banker's Algorithm
    • Module 4: Virtual Memory & Paging
  3. Computer Networks (CN) - 4 Credits
    • Module 1: OSI vs TCP/IP Reference Models
    • Module 2: Data Link Layer & Error Detection (CRC)
    • Module 3: Network Layer & IP Addressing (IPv4 vs IPv6)
    • Module 4: Transport Layer Protocols (TCP 3-way handshake vs UDP)
