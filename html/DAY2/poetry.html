Testing Preformatted Text vs Normal Paragraphs

If you write a poem in a normal <p> tag, HTML ignores your line breaks:

Chai in the morning, Code in the night, One missing semicolon, Ruins the fight.

Now written properly with <pre> tag (preserves exact spacing & tabs!):

    Chai in the morning,
        Code in the night,
    One missing semicolon,
        Ruins the fight!
                — Kushal (2 AM thought)
