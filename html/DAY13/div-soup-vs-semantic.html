Div Soup (The Bad Way) vs Semantic HTML (The Clean Way)

Bad Code (Div Soup):

<!-- Notice how everything is a div with endless classes! -->
<div class="site-header-wrapper">
  <div class="site-title">My Blog</div>
  <div class="menu-container">
    <div class="menu-item">Home</div>
  </div>
</div>

Good Code (Modern Semantic HTML5):

<!-- Clean, meaningful tags that screen readers understand! -->
<header>
  <h1>My Blog</h1>
  <nav>
    <ul>
      <li><a href="#">Home</a></li>
    </ul>
  </nav>
</header>

Lesson learned: Always choose the semantic tag before reaching for a <div>!
