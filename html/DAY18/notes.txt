MILESTONE REACHED: 18 CONSECUTIVE DAYS OF HTML COMPLETE! 🎉

Today I built my biggest project so far: A full 4-page connected personal website without using any CSS frameworks or templates, purely using clean, semantic, accessible HTML5!

What I built in `kushal-hub/`:
1. `index.html`: Home page with personal background, photo, quick elevator pitch, and education table.
2. `projects.html`: Portfolio gallery showing all the mini-projects built over the last 18 days with links and descriptions.
3. `skills.html`: Detailed breakdown of my HTML5 knowledge, semantic tags checklist, and study resources used.
4. `contact.html`: Accessible contact form with Indian mobile number validation, PIN code, and subject options.
