HTML Projects Archive (Days 1 – 18)

Here are some of the practical exercises and projects built during this module:

1. Vande Bharat Express Timetable (Day 9)

A comprehensive railway timetable showcasing complex merged cells using colspan and rowspan. Built with semantic <thead>, <tbody>, and <tfoot>.

→ View Vande Bharat Timetable

2. Swiggy Food Order Simulation (Day 11)

An interactive food ordering interface demonstrating radio button groupings for dietary preferences, checkboxes for extra toppings, and grouped dropdowns with <optgroup>.

→ View Swiggy Order Form

3. Indian KYC & Verification Form (Day 12)

A secure client-side form validation project utilizing custom Regular Expression patterns for 10-digit Indian mobile numbers (+91), Income Tax PAN card formats, and 6-digit postal PIN codes.

→ View Indian KYC Verification Form

4. Authentic Kadak Masala Chai Recipe (Day 7)

A multi-tier nested list project demonstrating ordered lists, unordered checklists, and description glossaries for ingredients and preparation steps.

→ View Chai Recipe Page

5. TechIndia Daily News Portal (Day 13)

A full semantic newspaper layout replacing generic div soup with landmark tags like <header>, <nav>, <article>, <section>, and <aside>.

→ View TechIndia News Portal
