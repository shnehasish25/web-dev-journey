Iframe Sandboxing Notes

Why the sandbox attribute exists:

If you embed an external site you do not fully trust, you can add sandbox to lock it down:

  • sandbox="": Blocks everything (scripts, popups, forms).
  • sandbox="allow-scripts": Lets JavaScript run inside the iframe.
  • sandbox="allow-same-origin": Lets the frame retain its origin identity.
