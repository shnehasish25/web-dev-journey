Day 15 - Modern HTML5 Tags (Details, Dialog, Progress & Meter)

Today's focus: HTML5 features that used to require heavy JavaScript plugins!

Learnings:
1. <details> and <summary>:
   - Creates a native accordion/collapsible dropdown with ZERO JavaScript!
   - Clicking the <summary> toggles open and close.
   - You can add the 'open' attribute to make it open by default.
2. <dialog>:
   - Creates an accessible native modal popup window!
   - Can be opened natively or with dialog.showModal().
3. <progress>:
   - For showing ongoing task progress (e.g. file download, battery charging).
   - Attributes: value="65" max="100".
4. <meter>:
   - For measuring a scalar value within a known range (e.g. temperature, disk usage, exam score).
   - Attributes: min, max, low, high, optimum, value.

Mind-blown today: You can build a complete FAQ accordion without a single line of JS or CSS!
